# COMP30023-Project-2
RPC Simulation Implementation

This RPC implementation is one of the project from the Computer System course in the University of Melbourne. The task here is to design and code a simple Remote Procedure Call (RPC) system using a client-server architecture. The RPC system is implemented in 2 files, called `rpc.c` and `rpc.h`.

The testing is done by running server and client program on the same VM.
